# ITSE1311TermProject
A multi‑page, responsive web store built for ITSE 1311 Beginning Web Programming.

# Overview
This site simulates a simple e‑commerce experience with a homepage, product listings, a shopping cart layout, and a contact page.
It focuses on clean structure, consistent navigation, and accessible styling.

# Features
* Responsive design using mobile‑first CSS
* Global navigation bar shared across all pages
* Product listing pages with organized layouts
* Shopping cart section prepared
* Contact page with a clean, accessible form
